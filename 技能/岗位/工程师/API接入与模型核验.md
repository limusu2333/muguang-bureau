# 岗位技能 · API接入与模型核验
> 目的：让工程师接模型/API时核对真实返回，不把花名册登记值当事实。

## 接入清单
1. 读取 `花名册.yaml`：provider、model、base_url、key_env、modality。
2. 读取 `.env.example` 和现有接入层，确认密钥只经环境变量。
3. 做低成本真实请求，记录服务端 `model` 字段、状态码、失败阶段。
4. 区分登记值、请求值、服务端返回值、模型正文自称。

## 失败分类
- 缺 key：说明缺哪个环境变量，不输出值。
- 鉴权失败：说明 provider/base_url/状态码。
- 限流/超时：说明 timeout、重试次数、是否建议稍后。
- 响应格式异常：保留短摘要，不能吞掉。
- model 不一致：报告风险，交项目经理判断。

## 输出格式
`登记模型 / 服务端model / 一致性 / 失败阶段 / 建议`
