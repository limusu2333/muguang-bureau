# 岗位技能 · 制度同步与读者视角
> 目的：让文案工程师从“陌生接任者能不能懂”出发同步 README、班规、核对表和手册。

## 同步顺序
1. 先确认代码行为或制度决定已经落地。
2. 找到需要同步的入口：README、班规、能力核对、岗位说明、手册。
3. 删除或改正会误导接任者的旧路径、旧岗位名、旧规则。
4. 保留历史记录的历史性，不把旧日志当当前状态。

## 读者视角检查
- 新窗口第一次打开能不能知道现状。
- 能不能区分已完成、待验证、历史记录。
- 路径是否可点击/可定位。
- 术语是否说人话。

## 输出格式
`同步对象 / 为什么要改 / 当前状态 / 历史保留 / 读者风险`
