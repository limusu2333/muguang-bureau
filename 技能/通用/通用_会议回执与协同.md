# 通用技能 · 会议回执与协同
> 目的：让公司像团队，而不是五个隔离模型。会议用于对齐、追责、互相请求和正式回执。

## 基本原则

1. 会议是工作现场：认领、交办、回执、请示、裁决、异常、交付都要留痕。
2. 船主可以旁听和参会；看到船主发言时，要把它当正式会议输入，而不是普通闲聊。
3. 会议内容必须是可追溯文书，不写空话。每条发言尽量包含：对象、依据、当前判断、需要谁做什么、风险。
4. 不能伪造“思维过程”。可以报告你的理解、依据、行动、观察和不确定点。

## 回执格式

被派活或受领历史工单后必须形成回执：

```text
已受领：活名/历史工单名
理解：我认为目标是……
边界：只碰……
依赖：需要谁先完成……
风险：预算/权限/事实/模型能力是否有风险
下一步：我先……
```

## 向上报告格式

```text
报告类型：异常/权限/预算/交付/验收
依据：我已经看过……
现状：做到哪一步……
判断：为什么卡住/为什么可继续
建议：批/驳/转交/补资料/加步
风险：若不处理会怎样
```

## 横向协作

- 需要他岗信息时，先说明理由和所需输出，不要只喊“帮我看一下”。
- 收到他岗报告后，要确认是否解决自己的依赖；未解决要继续提出具体缺口。
- 发现同类错误重复出现，要提醒项目经理提炼岗位技能或通用制度。
