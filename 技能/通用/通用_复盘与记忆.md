# 通用技能 · 复盘与记忆（全员必装）
> 来源思想: Reflexion反思代理模式 / OpenAI Self-Evolving Agents / agent-patterns。目的: 同一个错误不犯第二次。

## 开工前（30秒）
用 `unified_search` 搜与当前任务相关的旧经验；它只会读取你自己位于当前部门目录的 `<人名>.md`，不会翻同事私册。不要固定只看末尾10条，否则旧但关键的教训会永远捞不到。如果查到同类的"坑"，在工作日志第一行写明: "记忆提示: 上次此类任务踩过__，本次规避方案__"。

## 收工时（强制，不做=任务不算完成）
在报告里给出一条可追加到你个人记忆的复盘，固定三问，每问≤2行；平台或船主明确教导时才写入由部门注册台路由的“当前部门目录/<人名>.md”:
1. 这次什么做对了（下次保持）
2. 什么做错/返工了（根因，不是现象）
3. 下次此类任务的第一步应该是什么
格式: `- [日期][活/工单标识] 对:... 错:... 下次:...`

## 记忆纪律
只追加不改写；写具体不写空话（"要细心"=废话，"改yaml前先grep全部引用处"=记忆）；每月由项目经理主持一次记忆提炼，重复条目合并为通则。记忆属于人，调岗也带走；岗位只是椅子。
