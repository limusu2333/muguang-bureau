# 房间/部门架构 调研定论（2026-07-09 · 舟五路并行联网调研）

**船主问**：把 agent 扔进不同部门（编程部/编辑部/经理办公室）、每个做成实体房间，靠谱不？有没有最新案例？

**一句定论**：靠谱在"壳"，不靠谱在"内核"。房间当【叙事外壳＋上下文隔离容器＋留痕工作台】——有先例、贴合"过日子"劲；房间当【活在里头自主发生＋部门间动态开会编排】——最贵最脆，证据几乎一边倒反对。

## 硬证据
- 28 种多 agent 配置（3模型×100题）**全部输给单 agent**（-4.4%~-35.3%），主因协调开销（MDPI 14/24/4883）。
- 多 agent ≈ 单线程对话 **15× token**（Anthropic 披露）。
- ChatDev 独立评测基线成功率 **~25%**，堆角色层级只 +14%，仍玩具级。
- 失败 **~79% 发生在"房间接缝处"**（规格没写清＋交接对不齐；MAST arXiv 2503.13657）；房间越多、墙越多、接缝越多。
- 给 agent 挂"资深专家/总监"头衔对答对率**无统计显著提升**（162人设×2410题×9模型；arXiv 2311.10054）——头衔是仪式感，能力来自工具/上下文/验收。

## 能抄的（点名）
1. **Anthropic 多agent研究系统**（现役，+90.2%）：房间只干"并行找/查/分析"，写+汇总+拍板收回一条主线；派活四写死＝目标+交付格式+可用工具+边界。
2. **斯坦福小镇 Generative Agents**（房间隐喻奠基）：世界→区域→物件 可寻址树；每间房自持状态，进屋才看得见/拿得到。
3. **MetaGPT**（ICLR2024）：房间之间交**固定格式产物**（文档/工件），不靠聊天连。
4. **CrewAI 层级流程**：≈项目经理派活+验收+打回；但**只在活真会临时分叉才上经理层**，固定流程上经理层纯烧钱（+30-50% token）。
5. **Concordia / Game Master**（DeepMind）：每间房配一个"管家"agent 守状态/裁决写入，别人人乱写同一块状态。
- 最新但证据弱（别当定论）：OrgAgent(三层公司结构,单篇未复现,arXiv 2604.01020)、IndoorWorld(2025预印本,arXiv 2506.12331)。

## 红线（会翻车）
- 共享上下文 vs 房间隔离 = 近乎无解的两难：墙硬→各房间看不见彼此决策拼不拢（Cognition的Flappy Bird：一个画马里奥背景、一个画不搭的鸟）；墙软→退化成大单体、房间只剩装饰还多交接开销。
- **紧耦合的活别拆房间**（Cognition挺反两派唯一共识）：写连贯代码/连贯文章/连贯人格——别拆；只有"各查各的最后汇总"才值得分房。
- 5个拆房信号（中一个就退回流水线）：①出错说不清错在哪房 ②加房只增延迟不增质量 ③房间互相复制粘贴同一上下文 ④其实是固定流程（该写死流水线）⑤经理agent主要在转发消息不在决策。

## 对咱们的建议
**外壳重装、编排内核轻装。** 房间做实（有名字/能进/自留痕——你项目室追溯+大厅统一+右栏拍板已在正确一侧，别推翻）；固定流程用写死流水线（省钱可预测、错一眼看出）；只有"各查各最后汇总"才开并行房；写/拍板收一条主线；房间之间交文档不交口水；留一道真验收门（老纪当真门、不过打回）；盯5个信号，中一个拆房退流水线。

**⚠️最重边界**：这套只对**开发公司**成立。**别把房间/部门搬到小酒本人身上**——"她是谁"是紧耦合、必须人格连续，正落在两派都判"别拆"的禁区；越单线程/连续/共享上下文越稳。开发公司可分部门，小酒本人不能被分进部门。这两件别混。
