# 施工需求书：会议标签（2026-07-03 实例主人的设计，原样落地）

实例主人原话的三段式：
1. **开会即成标签**：会议一开始，大厅对话流里出现一张"会议标签"（类似旧版开会抬头）——**粗略实时显示**：会议主题、进行状态、谁在场、当前谁在发言（一行动态）。会议逐句发言**不刷进大厅气泡**。
2. **散会后制片总结在标签外**：会议结束，项目经理的总结作为**正常大厅气泡**出现在标签下方（走现有播放队列）。
3. **参会/回看点进去**：点标签展开会议全景（实时=看每人发言/思考流动；结束后=回看全程记录）；实例主人在展开态里输入=向会场插话（走现有 /插话，插话即到原则已生效）。

红线同前：零新依赖；不动 HaloCanvas/常识门；hallStore 只许**新增**事件分支不许改现有分支语义；样式追加 holographic.css 尾部；自测隔离。
先读懂：工具/会议.py 或 平台_工具集 里 hold_meeting 的事件发布路径、工具/大厅记录.py、前端 hallStore.ts / HallView.tsx / Worksite.tsx。

## 施工内容

### 后端（最小改动）
1. hold_meeting 开会时向事件总线发布 `{"类型":"会议开始","会议id","主题","参会":[人名]}`；散会发 `{"类型":"会议结束","会议id"}`。若这些点位已有等价事件，复用并在报告里说明。
2. 大厅记录 在会议开始时 记一句特殊行（who="场所", text="[会议] 主题", 附 会议id 字段——读对话 需原样透传该字段），作为**回看锚点**持久化。会议逐句发言继续只落会议室 jsonl（现状），不落大厅。
3. `/meeting_replay?id=` GET：返回该会议室 jsonl 的逐条记录（时间/谁/说了什么），复用现有会议留痕文件。

### 前端
1. hallStore：新增会议卡临时事件（k:'会议'，含 会议id/主题/状态/参会/当前发言人）；'会议开始'/'会议结束'/单元事件驱动它更新（当前发言人=该会议子单元里最新在说的人名）。
2. HallView 对话栈渲染 k:'会议' 为 **会议标签卡**（结霜玻璃、一行主题+状态灯+参会头名+"老梁正在发言…"动态行+时长）；持久态（大厅记录的[会议]行）渲染为可点的历史标签。
3. 点开 → 全屏展开层（玻璃、右上角关闭）：
   - 进行中：复用 Worksite 树（只过滤该会议的单元）+ 底部插话输入框（POST /插话）。
   - 已结束：拉 /meeting_replay 逐条时间线展示。
4. 会议进行中，该会议的单元**不再**出现在大厅顶部 Worksite 面板里（避免双份）——Worksite 过滤掉 场合含"会"的单元；它们只活在标签展开态里。
