# 抄件笔记：AI 语音球体 / 粒子状态视觉语言

### VoiceParticles：粒子群

默认：`size=300`、主色 `#06B6D4`、副色 `#8B5CF6`、`particleCount=100`、`particleSize=3`、`speed=1`。出处：`VoiceParticles/index.tsx:28-37`。  
初始化：粒子随机位置；`vx/vy=(random-0.5)*2`；尺寸 `random*particleSize+1`；透明度 `0.5-1.0`。出处：`VoiceParticles/index.tsx:52-66`。  
音量平滑：`1 - pow(0.1, deltaTime / 16.67)`。出处：`VoiceParticles/index.tsx:91-94`。

状态行为：

| 状态 | 行为 |
|---|---|
| idle | Brownian 漫游：`x += vx*speed*0.5`，越界从另一边包回。出处：`VoiceParticles/index.tsx:103-113` |
| listening | Swirl 涡旋：目标半径 `50 + volume*100`；回拉力 `(dist-targetRadius)*0.05`；切向旋转加速度 `sin(angle)*2*speed` / `-cos(angle)*2*speed`；阻尼 `0.9`。出处：`VoiceParticles/index.tsx:114-137` |
| speaking | Pulse 外冲：`pulseForce=volume*50*speed`，`returnForce=(dist-100)*0.05`，加速度乘 `0.1`；阻尼 `0.8`。出处：`VoiceParticles/index.tsx:138-156` |
| thinking | Jitter/orbit 快速绕行：角度每帧 `+0.1*speed`，半径保持。出处：`VoiceParticles/index.tsx:157-165` |

绘制透明度：`particle.alpha * (0.5 + volume*0.5)`。出处：`VoiceParticles/index.tsx:167-172`。  
过渡：无专门爆发/收缩动画；状态切换后沿用现有粒子位置和速度，靠体感连续。

### Shader 视觉语言

球体是三层 `SphereGeometry(scale, 80, 80)`。出处：`voiceorb/app.js:356-360`。  
每层 shader uniform：`layerOffset=index*2.0`，`sphereColor`，`opacity`，`chromaticAberration`。出处：`voiceorb/app.js:361-378`。  
光照：ambient `0xffffff, 0.4`；pointLight1 `0x667eea, 0.6`；pointLight2 `0x764ba2, 0.4`。出处：`voiceorb/app.js:391-402`。

顶点形变：  
- 三组 wave：`pos.y*2.5/time*1.5`、`pos.x*3.0/time*1.8`、`pos.z*2.8/time*1.6` 等；  
- 两层 noise：`pos*1.2 + time*0.3`、`pos*2.0 - time*0.2`；  
- 形变强度：`(wave1+wave2+wave3)*0.008 + noise1*0.008 + noise2*0.007`；  
- 音频乘子：`0.3 + audioLevel*0.6`。  
出处：`voiceorb/app.js:226-243`。

片元颜色：  
- Fresnel 边缘光：`pow(1-dot, 2.0)`。出处：`voiceorb/app.js:277-281`。  
- 彩虹位移：normal 的 x/y/z 系数 `0.5/0.2/0.1`，再加位置 shimmer `0.01`。出处：`voiceorb/app.js:282-292`。  
- 色差：`chromaticAberration * fresnel`，红蓝 hue 偏移 `±0.15`。出处：`voiceorb/app.js:297-314`。  
- 彩虹混合：`holographicIntensity=fresnel*0.6+0.2`，再乘 `0.6` 混入。出处：`voiceorb/app.js:316-318`。  
- 额外边缘亮度：`fresnel * chromaticAberration * 0.15`。出处：`voiceorb/app.js:320-321`。  
- shimmer：`sin(x*8 + y*6 + time*2)*0.04 + 0.96`。出处：`voiceorb/app.js:323-331`。

### 状态过渡

`setState` 里颜色、透明度、旋转速度、baseScale 是立即写入 uniform/userData；没有颜色 lerp。出处：`voiceorb/app.js:418-463`。  
真正平滑的是整体 scale：  
- listening 真实麦克风：`volumeScale=min(1,audioLevel*2.5)`，小于 0.1 时再乘 2；目标 scale=`1 + min + volumeScale*(max-min)`。出处：`voiceorb/app.js:637-657`。  
- thinking：`thinkingPulse=(sin(time*1.5)+1)/2`，映射到 `0-0.15`。出处：`voiceorb/app.js:658-666`。  
- speaking：TTS 估算音量 `0.6 + sin(3Hz)*0.2 + sin(12Hz)*0.15 + sin(0.5Hz)*0.1`，clamp 到 `0.2-1.0`；再映射到 `0.05-0.22`。出处：`voiceorb/app.js:560-570`、`voiceorb/app.js:667-680`。  
- scale smoothing：真实 listening 用 `0.25`，其它 pulsate 用 `0.15`，非 pulsate 回 1.0 用 `0.1`。出处：`voiceorb/app.js:682-690`。  

状态按钮 UI 自身有 `transition: all 0.3s ease`，speaking 按钮 pulse `1.5s infinite`，start 按钮 active pulse `2s infinite`。出处：`voiceorb/style.css:152-183`、`voiceorb/style.css:235-293`。

## 3. voice-orb-visualizer

License：MIT。出处：`voice-orb-visualizer/package.json:39-40`、`voice-orb-visualizer/LICENSE:1-20`。  
技术形态：Canvas 2D blob，不是 Three.js。它不定义 `idle/listening/thinking/speaking`，而是用 audio mode 和音量强度状态。

### 模式定义

`AudioMode = microphone | assistant | test | stopped`。出处：`voice-orb-visualizer/src/types.ts:75`。  
options 里可配置初始 `mode='microphone'`，但 `stopped` 是运行态。出处：`voice-orb-visualizer/src/types.ts:14-24`。  
`startMicrophone()` 进入 microphone；`startAssistant()` 进入 assistant；`startTest()` 进入 test；`stop()` 进入 stopped、清音频、清 forces、reset visual state。出处：`VoiceOrb.ts:170-215`。

### 默认视觉 / 音频参数

默认：`radius=100`，`padding=10`，主色 `#2563eb`，gradient `#2563eb → #81e6d9`，`strokeWidth=0`，`opacity=1`。出处：`VoiceOrb.ts:42-58`。  
默认音频：`fftSize=512`，`smoothingTimeConstant=0.8`，`autoCalibration=true`，`volumeLerpFactor=0.15`。出处：`VoiceOrb.ts:59-70`。  
默认运动：`pointCount=24`，`noiseIntensity=0.3`，`noiseSpeed=1.0`，`forceStrength=1.0`，`forceDecayRate=1.0`，`animationSpeed=1.0`，`maxOffset=50`，`fadeInMs=300`，`fadeOutMs=1200`。出处：`VoiceOrb.ts:71-80`。  
性能：`fpsLimit=60`，DPR capped at 2。出处：`VoiceOrb.ts:82-89`、`VoiceOrb.ts:140-146`。

注意：`noiseIntensity/noiseSpeed` 在 options 里定义，但主绘制实际用的是固定正弦噪声公式；不要误以为它们完整接入了形变。实际公式见 `VoiceOrb.ts:500-510`。

### 音频阈值 / 校准

AudioPipeline 初始阈值：`baselineNoise=0.02`，`sensitivity=0.08`，`loud=0.4`，`veryLoud=0.7`，`adaptiveGain=1.0`，音量历史 100 帧。出处：`audio-pipeline.ts:17-35`。  
麦克风：关闭 echoCancellation/noiseSuppression/autoGainControl；使用 `fftSize` 和 `smoothingTimeConstant`。出处：`audio-pipeline.ts:55-83`。  
校准时长 `1000ms`；baseline 取 median 且至少 `0.01`；动态阈值：`baseline+0.015`、`baseline+0.08`、`baseline+0.2`；adaptiveGain：`noiseRange>0.05 ? 1.2/noiseRange : 2.5`，再 clamp 到 `1.0-6.0`。出处：`audio-pipeline.ts:120-176`。  
麦克风处理：先减 baseline，再乘 adaptiveGain；50 帧以上做极慢增益自适应，目标平均音量 `0.3`，步长 `0.001`，gain clamp `0.5-4.0`。出处：`audio-pipeline.ts:179-209`。  
assistant 模式：音频文件只做 `rawVolume*2.0` 后 clamp 到 1。出处：`audio-pipeline.ts:242-247`。  
test 模式：`abs(sin(performance.now()*0.005))*0.3 + random*0.1`。出处：`audio-pipeline.ts:214-218`。

### 视觉状态语言

它按音量强度分三层内部状态：

| 内部状态 | 条件 | 行为 |
|---|---|---|
| gentle | `effectiveVolume > sensitivity` 但没到 loud | `moveAmount=(volume-sensitivity)*12`，`moveSpeed=1.2+adjusted*2` |
| loud | `effectiveVolume > loudThreshold` | `agitation=(volume-loud)*3`，`moveAmount=agitation*20`，`moveSpeed=1.5+agitation*3` |
| very_loud | `effectiveVolume > veryLoudThreshold` | `agitation=(volume-veryLoud)*2`，`moveAmount=agitation*30`，`moveSpeed=2+agitation*6`，叠两组 sin/cos 位移 |
出处：`VoiceOrb.ts:421-452`。

位置约束：targetX/Y clamp 在中心 ± `maxOffset`，默认 ±50。出处：`VoiceOrb.ts:468-471`。  
位置平滑：`positionSpeed = 0.02 + agitation^2 * 0.06`。出处：`VoiceOrb.ts:473-477`。  
没活动时回中心：`currentX/Y += (target-current)*0.05`。出处：`VoiceOrb.ts:398-404`。

### Blob 形变

每帧 `pointCount=24` 点。出处：`VoiceOrb.ts:483-488`。  
半径构成：基础半径 + forceInfluence + 三组音频波 + 有机噪声。出处：`VoiceOrb.ts:490-510`。  
音频波：`audioAmplitude=(effectiveVolume-sensitivity)*40*fadeMultiplier`；wave1 `sin(angle*2 + time*2)`，wave2 `sin(angle*3 - time*1.5)*0.6`，wave3 `sin(angle*1.5 + time*2.5)*0.4`。出处：`VoiceOrb.ts:496-503`。  
有机噪声：`sin(angle*4 + time*0.6)*4 + sin(angle*5 - time*0.4)*2`，再乘 fadeMultiplier。出处：`VoiceOrb.ts:505-507`。  
半径限制：最小 `radius*(0.6+(1-fade)*0.4)`；最大 `radius*(1+(1.8+adjustedVolume*0.7-1)*fade)`。出处：`VoiceOrb.ts:512-515`。  
曲线：二次曲线 `quadraticCurveTo`，控制点是当前点，终点是相邻点中点。出处：`VoiceOrb.ts:525-552`。

### ForceSystem：音频热点冲击

创建条件：`smoothedVolume > dynamicSensitivityThreshold`。创建概率 `(smoothedVolume-threshold)*0.5`。出处：`forces.ts:21-33`。  
新 force 参数：角度随机；强度 `10 + delta*50`；life `1.0`；decay `0.008 + random*0.012`；speed `0.3 + random*1.0`；maxDistance `20 + delta*60`。出处：`forces.ts:33-42`。  
衰减：`fadeDecay=(1-fadeMultiplier)*1.5`；`life -= decay*(1+fadeDecay)`；`distance += speed`；角度每帧 `+0.005`。出处：`forces.ts:58-66`。  
影响范围：角距离 falloff `1 - angleDiff/(π*0.4)`；距离生命周期 `sin(distance/maxDistance*π)`。出处：`forces.ts:72-90`。

### 过渡 / 回落

无 mode 间专门爆发动画；mode 切换主要改变音频来源。出处：`VoiceOrb.ts:170-215`。  
音量回落：`fadeProgress=min(timeSinceAudio/fadeOutMs,1)`，默认 `fadeOutMs=1200`；`fadeFactor=1-easeOutCubic(fadeProgress)`。出处：`VoiceOrb.ts:321-328`、`utils.ts:1-6`。  
音量平滑：`smoothedVolume += (targetVolume-smoothedVolume)*volumeLerpFactor`，默认 0.15。出处：`VoiceOrb.ts:326-329`。  
fadeMultiplier：音量下降时 `*0.985`，上升时 `+=(1-fade)*0.08`，clamp 到 0-1。出处：`VoiceOrb.ts:330-338`。  
时间推进：有活动时 `time += 0.006`，安静时 `time += 0.001`。出处：`VoiceOrb.ts:375-380`。

## 横向对比

| 项目 | 状态模型 | 最值得抄的点 | 风险 |
|---|---|---|---|
| react-ai-voice-visualizer | 明确四态：idle/listening/thinking/speaking | 每态参数表；粒子四态行为非常清楚；VAD 小状态灯可直接借鉴机制 | VoiceOrb 的 `stateTransitionRef` 没真正用于插值，别照抄为“有状态过渡” |

| voice-orb-visualizer | mode + 音量强度状态 | fadeOut、force 热点、blob 形变、动态阈值校准 | 没有语义态，只是输入源和音量强度；要自己映射到待机/思考/工作中 |

## 可抄清单：给 canvas 2D 粒子星球

我们的三态：待机 / 被唤醒思考 / 工作中，外加“光潮过渡”。

按性价比排序：

1. **状态参数表**
   - 抄 `react-ai-voice-visualizer` 的做法：每态只改 `noiseScale / noiseSpeed / glow / rotation / pulse / audioReactivity`。
   - 建议：待机 `noise=0.06`、`glow=0.4`、`rotation=0.05`；思考 `noise=0.12`、`noiseSpeed=2`、`rotation=1.5`、`pulse=4`；工作中 `audioReactivity=0.8-1`、`glow=1.1`。
   - 依据：`VoiceOrb/index.tsx:65-104`。

2. **粒子四态行为映射**
   - 待机：Brownian 漫游，速度乘 `0.5`，越界包回。
   - 被唤醒思考：jitter/orbit，角度每帧 `+0.1*speed`。
   - 工作中：pulse 外冲，`pulseForce=volume*50*speed`，阻尼 `0.8`。
   - 监听/收音场景可选：swirl，目标半径 `50+volume*100`。
   - 依据：`VoiceParticles/index.tsx:103-165`。

3. **光潮过渡**
   - 从 VAD 的外环抄机制：环从 scale 1 到 2，透明度 1 到 0，时长 `1.5s`。
   - 用在三态切换瞬间：一圈或两圈 radial wave，不抄 DOM，只抄动画概念。
   - 依据：`VADIndicator/index.tsx:55-64`、`VADIndicator/index.tsx:169-177`。

4. **音量平滑 + 回落**
   - 工作中音频驱动别直接用 raw volume；用 `lerp`。
   - 简版：`smoothed += (target-smoothed)*0.15`。
   - 高级版：静音后 `fadeOut=1200ms`，`fadeFactor=1-easeOutCubic(t)`，让星球慢慢圆回来。
   - 依据：`voice-orb-visualizer/src/core/VoiceOrb.ts:321-338`。

5. **内部 force 热点**
   - 声音或工作事件触发局部鼓包：概率 `(volume-threshold)*0.5`，强度 `10+delta*50`，生命周期从 1 衰减。
   - 适合“工作中”表现：不是整个球一起抖，而是局部有力场涌动。
   - 依据：`voice-orb-visualizer/src/core/forces.ts:21-66`。

6. **三层球 / 三层粒子**
   - 主体层 `scale=1 alpha=0.8`，内层 `0.95/0.5`，外晕 `1.1/0.3`。
   - canvas 2D 可用三批粒子或三条闭合 blob 代替。
   - 依据：`VoiceOrb/index.tsx:303-306`。

7. **思考态不用音频，靠高频旋转和规律脉冲**
   - thinking 在 React 球里 `audioReactivity=0`，但 `rotation=1.5`、`pulse=4`、`noiseSpeed=2`。
   - 这适合“被唤醒思考”：看起来脑内活跃，但不假装在听声音。
   - 依据：`VoiceOrb/index.tsx:85-94`。

8. **工作中 cadence**
   - 没真实音频时，用语音节奏模拟：短爆发、中句、长句、停顿四类随机节奏。
   - 可映射为“员工在工作”的呼吸：强度短促变化，而不是匀速呼吸。
   - 依据：`voiceorb/app.js:575-605`。

9. **动态阈值校准**
   - 如果接麦克风，先 1000ms 取环境 baseline，再设 `baseline+0.015/0.08/0.2` 三档阈值。
   - 适合后续语音态，不一定第一版做。
   - 依据：`audio-pipeline.ts:120-176`。

10. **Fresnel/色差只抄审美，不抄实现**
   - Three.js shader 的彩虹边缘和色差高级，但 canvas 2D 直接实现成本高。
   - 可以简化成：边缘粒子 hue ±小角度漂移，外圈 alpha 随状态放大。
   - 依据：`voiceorb/app.js:277-333`。

### 推荐落地版

- 待机：低速 Brownian + 轻呼吸；粒子透明度 0.5-0.7；外晕 `glow=0.4`。
- 被唤醒思考：粒子绕轨 / jitter；旋转速度提升到待机 20-30 倍；规律脉冲 `sin(t*2+angle*3)*0.15`；颜色偏紫/蓝。
