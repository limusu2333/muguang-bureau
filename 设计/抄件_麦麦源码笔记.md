## 一、评分门（reply_necessity.py，全参数照抄起步）

**公式**：`最终分 = max(0, (强相关 + 内容分 + 压力分 − 存在感惩罚) × (0.5 + 0.5×频率))`，**阈值=65**。

**照抄的常量与细节**（比 v3 方案里的猜测更细，以这份为准）：
- 强相关：被@=100 / 名字提及=80 / 私聊或focus=40 / 普通群消息=0
- 请求词分两档：直接（帮我/帮忙/能不能/可以吗/要不要）+20；**弱请求（需要/求/看看/试试）只在"直接上下文"（被@/被提及）才算分**——防"我需要睡觉"这种误触发
- "能不能"不在直接上下文时要求**句首**才算——细到这个程度
- 问题判定：怎么/如何/为什么/有没有；`(?<![这那没])什么`（"这什么/没什么"不算问）；`[吗呢]$` 且 4~80字；**过滤"？？？xx？？？"式假问题**
- 征询：你觉得/你认为/咋看/有什么建议；**"不怎么看"排除**；非直接上下文要求句中带 bot 名字
- 短反应集合：哈哈/哈哈哈/草/笑死/好/嗯/啊/哦/6/666/？/?——**整批都是短反应 −25**（单条>8字即不算短反应批）
- 长文本 ≥40字+5、≥120字+10
- 压力分 = min(40, 40×积压/阈值)，空窗超过平均消息间隔再+15（我们期1不做积压，压力恒0）
- **存在感惩罚 = min(45, 近300秒自己发言数×15) + min(40, 尾部连续自己发言数×20)**——防刷屏/防AI互怼的核心
- **别家AI点名正则**：`^(?:DeepSeek|ChatGPT|Grok|豆包|千问|元宝|通义|Kimi|Claude)[，,、\s]` → 喊别人时不抢话。我们进化成：**点名排他**（喊了群里任何一个人，其他人封顶30）
- 噪声清洗：@全体→空、引用前缀剥离、媒体占位（[图片：/[表情包:/[语音:）→空、合并转发→空——我们对应：附件占位与引用体不参与算分

## 二、防"唠叨王"双保险（turn_gates.py 空窗补偿，issue #1786 血案的修复）
1. `pending==0 一律不触发`——**纯沉默永远不能唤醒发言**；
2. 空窗折算量封顶 `阈值−1`——无论安静多久，必须至少有一条真实新消息。
→ 期3 做主动发言时这两条是铁律。

## 三、空闲指数退避（idle_backoff.py + 官方默认值）
- 连续 N 轮决定不说话后退避：**基准15s × 2^(n−起点)，封顶300s，起点=连续2次，积压≥6条击穿退避**
- focus 模式（正在专注对话）不退避；退避只作用于群聊
→ 期3 主动发言的节流器，参数照抄。

## 四、Planner 工具组（builtin_tool/，本人终审层的形状）
工具集：`reply`（msg_id 定点回复 + set_quote 引用开关 + reply_guide 给回复器的指引 + expression_intent 结构化语气意图）、
`wait`（**连续 wait 有上限，达到即强制休息**——runtime._try_enter_wait_state 计数）、
`send_emoji / send_image / switch_chat / fetch_history / query_memory / query_person_profile / tool_search / view_forward_message`。
→ 我们对应：本人终审=说/[沉默]（已有），**"等一等"暂不给**（我们每句话都是即时场，没有它的循环模型）；
`reply_guide/expression_intent` 思想可进化为"发言前自己想好语气"——已天然在 ReAct 里。
`query_memory/query_person_profile` 我们已有对应（Read/Grep 记忆库 + 大厅痕迹簿）。

## 五、顺手挖到的两座矿（不在群聊线，记账）
1. **A_memorix v2.0**（它内置的长期记忆子系统）：文本/关系/**Episode（情景）**/人物画像/检索调优统一运行时，
   工具接口 `search_memory(query, mode, limit, chat_id, person_id, time_start, time_end)`——
   带**时间范围与人物过滤的检索**，正是我们记忆 P5（向量/关键词双通道召回）的参照系。
2. **黑话参考（jargon_context_matcher.py）**：把群内学到的黑话按当前上下文**机械匹配**（不烧模型），
   以"[黑话参考] 仅作理解语境"注入——公司未来"说话像自己人/学船主的行话"可走这条线（配 learners/ 表达学习）。

## 六、适配映射（麦麦=单bot混人群 → 我们=五人常驻一群）
| 麦麦 | 我们 |
|---|---|
| 单 bot 对每批消息算一个分 | **五人各算各的分**（每人一份强相关/惩罚/频率） |
| effective_frequency（talk_value 滑杆） | 花名册每人 `发言频率` 字段 + 班子页滑杆 |
| 别家AI点名不抢话（正则） | 点名排他：喊了任何同事，其他人封顶30 |
| focus 专注槽（全局1个） | 暂不需要（我们没有多群） |
| 攒批处理（pending 积压） | 期1不需要（每句即时处理），压力分置0 |
| Planner 循环 + wait | ReAct 唤醒 + [沉默]协议（已有），不加 wait |
| 空窗补偿+退避 | 期3 主动发言专用，铁律照抄 |
