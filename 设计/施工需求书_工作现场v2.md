# 施工需求书：工作现场 v2——把"看见一群活人工作"的窗户还回来（2026-07-03 实例主人令）

背景：6-27 的工作现场（commit 94d7388，"从简陋卡到看见一群活人工作"）在深空全息装修中丢失。
数据层完好：hallStore.活人单元 里有每单元的 名字/岗位/父单元/状态/思考流/动作(工具+目标+结果+轮次)/发言/起止时间；runCard 有进度行（常识门判定等）。**只缺渲染。**

**验收基线 = 实例主人当年的五问 + 三条新账**：
①位置稳定 ②名字不错 ③真实工具可见（查了哪个文件/搜了什么）④每人可点开 ⑤分人分层级（PM顶层、参会者/子agent缩进）
⑥思维透明（思考流能看，deepseek两台有真思维流）⑦二级菜单（动作条目可再点开看结果全文）⑧美学融入深空全息（结霜玻璃、mono读数、人色=星球站位色）。

红线：不装依赖；不改 hallStore.ts / 后端 / HaloCanvas；新组件新样式追加，不重排既有布局逻辑；样式追加进 holographic.css 尾部。

## 施工内容

### 新组件 前端/src/components/Worksite.tsx
Props：`{ units: 活人单元[], runCard: RunCard | null, 工作中: boolean }`（类型均已存在于 api.ts/hallStore.ts）。

**挂载**（改 HallView.tsx，最小侵入）：hall-stage 内、对话栈上方渲染 `<Worksite …/>`；
显示条件：`工作中 || units.length > 0`；新任务开始 store 已自动清 units（不用管）。

**结构**：
1. 面板 = 结霜玻璃（照抄 .mem-panel 配方），max-height 42vh 内部滚动，宽度与对话栈一致。
2. 头部窄条：`现场 · N人` + runCard 最新一行进度（mono 小字，如"常识门：老纪（你被点名了）"），运行中带秒表（store 已每500ms tick）。
3. 单元树：按 父单元 建层级（父=null 或 "大厅群聊" 为顶层；子单元缩进 18px 带一根细连线）。
   每行（默认折叠）：`信号点 名字 · 岗位 —— 最新一行动态 —— 动作数 · 秒数`
   - 信号点颜色 = 该人星球站位色（老钟345/老梁210/阿强300/阿言255/老纪32，hsl），工作中呼吸动画，完成恒亮60%。
   - 最新一行动态 = 发言尾行 || 最近动作目标 || 思考尾40字 || "正在琢磨…"。
4. 点开一行（二级）分三区，各自可再展开（三级）：
   - **脑内**：思考流，mono 11px 暗色，默认尾部 240 字，点"看全部"展开全文（内部滚动 max 30vh）。没有思维流的模型显示"（思维未外露，看动作）"。
   - **动作**：每个动作一行 `工具名 → 目标（截80字）`，进行中转个小呼吸点；**点单个动作展开结果全文**（预格式化，max 24vh 滚动）。
   - **发言**：默认前两行，点开看全文。
5. 空态（工作中但单元未到）：一行 mono "正在唤醒…"。

### 样式（holographic.css 尾部追加）
- 面板玻璃同 .mem-panel；行 hover 微亮；展开区背景再暗半档（rgba(0,0,0,.25)）分层；
- 三级结果全文用等宽小字 + 内滚动；所有滚动条走现有全局样式；
- 动画只有信号点呼吸（复用 bdg keyframes），不加花活。
