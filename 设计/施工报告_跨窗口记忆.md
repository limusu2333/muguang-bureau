# 施工报告：跨窗口记忆与发言顺序

> **历史施工报告（2026-07-14 标记）**：本文记录 2026-07-03 当时的实现，不代表现役入口。现役搜索由 `unified_search` 统一覆盖公司文档、大厅原话、本人私册和公共图谱；`search_hall_history/semantic_search` 仅留底层兼容，现役记忆路径见 `设计/记忆系统_全图.md`。

日期：2026-07-03

## 改动文件

- `工具/会话摘要.py`：新增昨日大厅摘要生成。读取 `大厅/对话/YYYY-MM-DD.jsonl`，用文案岗蒸馏成 `MMDD 聊了...`，写入 `记忆库/会话摘要.md`，状态记在 `记忆库/.巩固状态.json` 的 `_会话摘要`，最多保留 40 行。
- `工具/大厅检索.py`：新增大厅历史索引和检索。SQLite 索引落 `运行状态/大厅索引.db`，支持增量重建、`搜历史()`、`翻近期()`。
- `工具/记忆巩固.py`：`巩固到期的人()` 开头顺路调用昨日摘要；失败只写 `记忆库/抽取日志.md`，不外抛。
- `工具/活_本人.py`：每次唤醒在“你的记忆”后注入 `会话摘要.md` 最近 30 行；`只发言=True` 改为最小只读工具箱，可翻大厅历史。
- `工具/平台_工具集.py`：注册 `搜历史` / `翻近期` 两个只读工具，单次返回截断到 1500 字内。实际 API 工具名用 `search_hall_history` / `recent_hall_chats`，避免 OpenAI 兼容接口拒绝中文工具名；提示里保留中文称呼。
- `工具/常识门.py`：普通名单按分数排序，同分随机抖动；直通名单保持点名 > 任务 > 全体 > 地盘优先。
- `工具/办公室.py`：顺序群聊改为可插队队列；同事非沉默发言后，用 `_提及检测` 回评唤醒未发言同事，每轮最多追加 2 人；相邻唤醒间加 0.8-2.0 秒随机错峰。

## 自测结果

- 编译：`.venv/bin/python3 -m py_compile` 覆盖全部改动 Python 文件，通过。
- 大厅检索：临时目录造 3 天假档案，中文关键词命中并带前后文；修改档案后增量重建命中新内容；强制禁用 trigram 后走 `unicode61 + LIKE`，中文仍可搜到。
- 会话摘要：临时目录假档案 + 假摘要器生成成功；第二次调用不重复；旧摘要裁到最近 40 行；状态键 `_会话摘要` 正确写入临时 `.巩固状态.json`。
- 常识门排序：假花名册下同一句普通聊天多次排序出现不同顺序；点名“老纪”时测试工程师稳定第一。
- 工具箱：`.venv` 下校验只发言工具箱 schema，实际工具名为 `search_hall_history` / `recent_hall_chats`。
