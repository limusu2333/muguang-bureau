# 群聊语义 v3 · 施工级方案（2026-07-03 船主已点头方向：搬麦麦两级骨架）

> v2 是调研定稿（为什么），这份是施工图（怎么干）。船主对本文件点头后才动代码。

## 0. 体验验收标准（先立靶子，施工完照着测）
| 场景 | 期望 |
|---|---|
| "老纪在吗" | **只有老纪**醒并回答；别人不动（老钟也不抢） |
| "@工程师 看下这个" | 只有阿强醒 |
| "大家好" / "都在吗" | 全员过门，各自判断，2~4 人接（不许全员轰炸式复读） |
| "哈哈哈哈" / "6" | 没人醒；若连发多句冷场，老钟兜底轻接一句 |
| "把首页那个bug修了" | 老钟必醒接活（可另有相关工种冒泡） |
| 聊到某人记忆里的事（如"上次验收漏跑回归那事"） | 那个人（老纪）大概率自己冒出来 |
| 两个AI互聊起来 | 存在感惩罚压住，不出现连环互刷 |
| 成本 | 普通闲聊每句唤醒 ≤2 人；点名 =1 人；纯语气词 =0 人 |

## 1. 架构与数据流
```
船主消息 → [常识门] 纯python对五人各打分(读大厅记录尾部)
              ↓ 过阈值者（0~n人；0人→老钟兜底）
          [并行唤醒] 只发言模式，带各自四区记忆 + 记忆命中提示
              ↓ 本人终审：说 / [沉默]（场所规则牌协议，不变）
          [播放队列] 谁先说完谁先到货，前端一次一人打字机（已建成，不动）
```
落点：`工具/常识门.py`（新）+ `办公室.py` 的群聊编排改为"先过门再唤醒"（替换现在的无差别五人全醒）。三层规则归位不变：这套门是**场所设施**（大厅的耳朵），写进场所文件；人的性格写人设；视觉不动。

## 2. 常识门评分细则（抄 MaiBot reply_necessity，按我们场子改）
对每人 p 计算：`最终分 = (强相关 + 内容分 + 任务分 − 存在感惩罚) × (0.5 + 0.5 × talk_value_p)`，**阈值 65**。

**强相关（每人各算）**
- 被 @p（@名字/@岗位）= 100（直通，其他人本句强相关记 0）
- p 的名字或岗位被整词提及 = 80
- 上一句大厅发言是 p 说的、且本句是疑问/回应式 = 40（接话惯性，adjacency pair）
- **点名排他**：本句点了别人（≥80 的人存在）且没点 p、也无全体词 → p 的总分直接封顶 30（喊别人不抢话）

**内容分（全员同值）**
- 真问题（怎么/如何/为什么/吗？…，过滤"？？？"式）+15
- 请求（帮我/帮忙/能不能/给我…）+20
- 征询（你们觉得/怎么看/有什么想法…）+20
- 全体词（大家/各位/都在/你们…）+30
- 长文本 ≥40字 +5，≥120字 +10
- 纯语气词（哈哈/草/6/？/。。。/emoji串）−25

**任务分**：含祈使+做事动词（修/改/做/查/写/部署/加/删…）→ 老钟本句直通 100（职责牌"任务必接"的场所执行），相关工种 +25。

**存在感惩罚（防AI互刷的现成答案，读大厅记录算）**
- p 近 5 分钟每说一句 −15（上限 −45）
- p 连续发言（中间无别人）每句 −20（上限 −40）

**talk_value**：花名册每人加 `发言频率` 字段（0~1）。初值：老钟 0.8 / 阿言 0.6 / 老梁 0.4 / 阿强 0.4 / 老纪 0.3。
**兜底**：无人过门且本句不是纯语气词 → 唤醒老钟（冷场兜底，职责牌已有）；纯语气词冷场连续 ≥3 句才兜底。

## 3. 本人终审（主权在人，改动极小）
- 唤醒上下文加一行来意说明："这句话过了你的耳朵（你被点名/话题相关/群里在征询），说不说仍由你判断，规则牌协议不变。"
- **记忆命中提示（兴趣=记忆激活的v1实现）**：唤醒前用关键词粗匹配该人四区记忆，命中则附"这句话碰到了你记忆里的：〈那几条〉"——他自然来劲，这就是"皮一下"的真来源。v2 升级为向量相似（记忆向量已有底子）。
- 规则牌补丁（治老纪误会）："在大厅说话＝把话直接说出来，你的发言本身就是回复，不需要写任何文件、不需要任何权限。"

## 4. 产品旋钮
- 班子页每人一根**发言频率滑杆**（写回花名册 talk_value；POST /crew_talk）。
- 免打扰/主动发言等旋钮留给下期。

## 5. 施工分期
- **期1（先干）**：常识门.py + 办公室编排接门 + 花名册字段 + 规则牌补丁 + 唤醒来意行。纯后端，当天可验。
- **期2**：班子页滑杆 + 记忆命中提示（关键词版）。
- **期3（下期单独立项，船主已同意缓）**：主动发言（冷场救场/主动找人）——必配指数退避、无人接茬即闭嘴、给记忆补"因"（麦麦#1786 与 AstrBot RFC #3497 的血泪）。这道题与小酒"主动消息"同源，郑重做。

## 6. 风险与对策
