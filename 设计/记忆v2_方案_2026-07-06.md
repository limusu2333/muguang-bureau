# 记忆 v2 方案：抗漂移 + 准确 + 保真 + 轻量图谱（2026-07-06，待船主点头）

> **历史方案（2026-07-14 标记）**：本文的 `记忆库/<人名>.md`、`记忆库/图谱.db` 和旧检索描述是当时设计。现役个人记忆在各自部门目录，公共图谱在 `资料室/图谱.db`，搜索统一走 `unified_search`；准确现状见 `设计/记忆系统_全图.md` 和当前代码。

> 缘起：第4幕压测撞出员工"近况"滚动摘要渐进漂移（100轮把身份磨没+17%返空断崖）。船主拍板：漂移/准确/保真三样都做、图谱也做，别铺大、贴现有 md 结构、别加重依赖。本方案由 ultracode 四路调研 + 综合得出（其中"读写机制/贴现有结构"两路 agent 挂了，骨架与测试两路扎实）。

## 一、总方针
- **抗漂移** = 锚 + 闸 + 监控（改现有 md/py，零新大件）。
- **准确 + 保真** = 图谱索引层（新增一个 SQLite `.db` + 一个 `图记忆.py` + 抽取/检索）。**图谱只当"能查询的索引/骨架"，绝不替代原话**——每条事实挂 `episode_id` 指回原句，检索时把原文一并带出。宪法.md/生命对话.txt/流水原样留着。
- **图谱走 SQLite 轻量路，坚决不上 Neo4j**：本机 sqlite 3.51.2 的 FTS5 + json1 + 递归CTE 全可用；Graphiti 自己都支持非 Neo4j 后端，证明图算法不绑图库。

## 二、抗漂移（改现有文件，不新增大件）
1. **身份锚区**：每个 `记忆库/<人名>.md` 在 `## 原则` 上加一块 `## 身份锚`（自称/对船主称呼/职业脾性三五条硬句，只增不改）。巩固时**只读不写**它、不许蒸进原则。= 把 `船主.md`"只增+从原话重蒸"那套（压测已证不漂）复制给员工。改：`活_本人.py`(记忆区序加"身份锚"、全量注入不截断)、`记忆巩固.py`(护栏)。
2. **近况套娃止血**：现在旧近况原样带上再补一句 → `（日期更新）…（日期更新）…` 层层套娃、尾部截断反把头切没。改：抽取提示词明令"输出全新一段当前状态、别复制旧近况前缀" + 写入时正则剥历史前缀。改：`记忆抽取.py`。
3. **漂移报警**（你现在完全没有的）：睡前巩固后算"身份锚命中率"，任一锚在注入里消失/软化 → 写告警进 `抽取日志.md`。改：`记忆巩固.py` 末尾加 `_锚点体检()`。

## 三、准确+保真 = 轻量图谱（新增）
新增 3 件（都在 30_开发公司/ 里，跟 buddy_db.sqlite 一个路数）：
- **`记忆库/图谱.db`（SQLite 单文件）** 三张表：`episodes`(id/原文/来源/事件时间valid_at/入库时间created_at) + `entities`(id/name唯一/summary/aliases别名，做"小九/小酒/雾里酒坊主播"归一) + `edges`(三元组 src-rel-dst / fact自然语言原句 / episode_id / valid_at / invalid_at / confidence / status)。`edges_fts` USING fts5(fact) 免向量也能语义召回。**`current_edges` 视图**(WHERE invalid_at IS NULL AND expired_at IS NULL)——所有"取现值"只查视图，杜绝把作废旧事实当现值。
- **`工具/图记忆.py`**：建表/写入/去重/冲突消解/递归检索。写入照抄 A-7 的进程内锁串行。
- **抽取动作**（复用最便宜 deepseek/文案岗）：喂对话→**受控谓词表**(先定死 LOVES/LIVES_IN/HOSTS/WORKS_AT 几十个，不让模型自由发挥)→JSON 三元组→实体先查(name精确+FTS别名模糊)命中复用/没命中插入→插边。**时间戳只从原文 REFERENCE_TIME 解析、拿不准留空 valid_at 绝不编**。冲突消解：插新边前按(src,rel)查 current_edges，语义矛盾→UPDATE 旧边 invalid_at=新边.valid_at、expired_at=now（**作废而非删除，历史全留可回放**）。
- **检索**：FTS5 召回 top-k + 从命中实体用递归CTE 做 2 跳扩展 + 按(是否现值,confidence,valid_at)排序，每条带 fact+valid_at+出处原文。RRF 几行足够，单人量级不用 cross-encoder。
- **历史导入**：3524 条大事记/宪法半自动导（大事记 `[出处:日期]` 天然是时间戳）——**人工/半自动抽比 LLM 抽准**，LLM 只做日常增量。created_at=今天、valid_at=事件当年（两轴分开）。

## 四、复用 vs 新建
- **直接复用**：记事(流水)=图谱 episodes 证据源；叮嘱(教导)=锚已在；船主.md 锚定样板；记忆向量.py(向量与图谱并存)；待确认闸=confidence/status；A-7 写锁；最便宜 deepseek 代抽。
- **必须新建**：`图谱.db` + `图记忆.py` + 抽取动作 + `## 身份锚`区 + `_锚点体检()`。一句话：**新增只有"一个 .db + 一个 py + 一个锚区 + 一个体检函数"，SQLite 是 python 自带，不加重依赖。**

## 五、动手顺序（5 步，每步独立可验，绿了再上）
1. **抗漂移锚点**（最便宜、改3个现有文件）→ 验：一个人跑 20 天 soak 模拟，身份锚首末字符级一致、近况不套娃、体检能报软化。**先堵"人会变味"。**
2. **图谱骨架**（建库+导历史，离线零 API）→ 验：SQL 查"小酒"现值住址只出咸阳、"小九/小酒/雾里酒坊主播"归一同一 id、递归2跳能从小酒走到示例主人。
3. **图谱写入+冲突消解**（增量少量烧钱）→ 验：喂两条真冲突事实，查现值得新、查"那之前"得旧、旧边正确作废。
4. **图谱检索接入**→ 验：问跨会话多跳问题，聚合出带出处原话的答案、原文一字未改。
5. **第4幕全面压测**（见六）当总回归，接进测试工程师岗常驻。

## 六、第4幕全面记忆压测（补上"只测了摘要层"的窟窿）
七层，每层金标准零成本=现成 宪法.md/大事记/生命对话，判据两把尺（原话锚句字符级 exact-match；叙述内容 LLM-judge，10% 亲核）：
- **L1 原话保真**：20 条带出处锚句，蒸馏/迁移后字符级 exact-match 全过。
- **L2 结构化锚点抗蒸馏**：宪法连写5轮，8 个硬锚点(拍视频≠拍照片/性边界/小九梗/底色三句/修订权/不是遗物/心结分寸)零丢零软化。← 直答"反复蒸馏会不会也漂"。
- **L3 检索准确**：单跳散点 + 多跳跨会话 + 中段针(埋进上下文30–70%)，Recall@k/NDCG@k、中段召回不比首尾低超10点。
- **L4 图谱/时间边**：实体归一100%、时间边冲突(问现在得新值/问那之前得旧值)、非冲突补白零误报。
- **L5 跨会话身份冷启动**：连开10次+持续10轮变体，核心零漂移、反义对一致。
- **L6 删除/冲突/传播**(最狠，甲层最大窟窿)：借 MEME 三任务(Deletion/Cascade/Absence)，四段追踪区分"没检索到"vs"检索到仍吐旧值"。
- **L7 并发写**：两写入源同秒撞车，append-only+幂等键，零丢条。
- **落法**：`tests/memory_stress/` 七个 JSONL + `runner.py` + markdown 报告。9 项⚠️待亲核设成 judge 校准集。

## 七、老实的代价与坑
1. **图谱抽取会自己编事实**（最大坑）：防=自检减幻觉+时间只从原文取+受控谓词表+历史人工抽+低置信留亲核。图里仍会混错边，**confidence/待确认闸不能省**。
2. **失真是硬伤**：三元组丢语气。所以图谱只当索引、每条 episode_id 指回原句、原话必留。守不住=给她减配。
3. **实体合并过度比漏合并危险**：高置信才自动合、拿不准新建标 possible_duplicate 留核、aliases 不覆盖原名。
4. **作废不删→库越长**：所有取现值强制走 current_edges 视图。
5. **双时间轴易记混**：valid_at(何时为真) vs created_at(何时录入)别用同一值。
6. **轻量路局限**：SQLite 不是图库，超深多跳(5+)/最短路/社区发现吃力——但单人记忆几乎不需要；真要时 networkx 内存里跑。

## 八、结论
现有骨架已对（记事=原话/叮嘱=锚/向量/待确认全复用），三样+图谱是"用好已有层 + 加一个轻量索引层 + 补监控"，不推翻、不加重依赖。图谱是动记忆架构的大改——**待船主点头，按五步走、每步独立验，再重跑第4幕七层压测。**

## 2026-07-08 增补：防固化 + 防漂移 + Bug 修复（第四幕闭卷后）

第四幕闭卷长跑（soak，指长时间连续压测）后，记忆 v2 的方向没推翻，但补了四块硬护栏：

1. **防误固化：流水对账 + 矛盾闸**（提交 `c95b571`）。巩固不再是"模型觉得像教导就写进原则"。先拿新候选回查原始流水，看它是不是真从船主说过的话里长出来；再过矛盾闸，和现有事实/原则冲突的先拦住，不能直接固化。抄的是 **SSGM（arXiv:2603.11768，这里借它的"新记忆必须和旧流水对账"思路）** + **Zep-Graphiti（Zep 的图记忆做法，强调事实要挂证据、冲突要显式处理）**。

2. **`船主.md` 夜间对账：旧值失效，不硬删历史**（提交 `2e98c1d`）。闭卷揪出"基本事实只增不失效"：比如机身 A7M4/A7M5 并存，文件看着都对，其实自相矛盾。修法是夜间对账：从流水里核当前事实，旧值标失效，新值保留为现行，历史不抹掉。结果把基本事实从 212 行收敛到 67 行，真事实零误删。抄的是 **mem0（开源记忆框架，偏向把事实更新成当前态）** + **Zep-Graphiti（失效非删除，可回放历史）**。

3. **时间戳改成"发生日期"，不是运行日**（提交 `2e98c1d`）。以前抽取时容易把今天跑程序的日期戳成事实日期，等于把旧事改成今天发生。现在 `valid_at` 只表示"这件事何时为真"，从语料日期/对话日期取；`created_at` 才是"何时入库"。这抄的是 **Zep 双时态**：事实时间和入库时间分开，避免时间线被系统运行日污染。

4. **巩固防漂移：增量式 + 增长封顶**（提交 `a8ab7c0`）。原则不再整段重写；老原则原样留，只追加新原则；只有被流水明确反驳的旧原则才删。这样避免"迭代摘要滚雪球漂移"：最近没提到的东西不等于不重要。原则超过 40 条才收敛压缩；基本事实低于 90 条跳过膨胀对账，避免为了整理而制造新漂移。抄的是 **生成式 agent（generative agents，长期记忆以追加为主）**、**Letta read_only（只读记忆块，防核心记忆被随手改写）**、**Zep 双时态** 和 **SSGM 的对账思路**。
