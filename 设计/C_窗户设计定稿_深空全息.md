## 一、血统与军规

血统：影视 FUI（贾维斯/Jayse Hansen 的悬浮语法 + HUDS+GUIS 行当共识）× Apple 光谱粒子。

**军规（违反=打回）：**
1. **无容器**：禁止圆角胶囊、卡片底框、徽章底色。信息悬浮在暗场上，用引线、刻线、留白建立结构。凡"底+框"先问能不能拆。
2. **色只上光**：底是近黑蓝炭 `#0b0c0f`；彩色只出现在发光体（光环光谱、琥珀刻线 `#e8a34c`、信号红 `#ff5f4d`、LINK 绿点）。禁止彩色填充面。
3. **一个活物**：光谱粒子环是全站唯一主角（公司的"在场"本体），其余一切安静。
4. **通知的形态是呼吸红点**，不是数字、不是徽章。
5. **文案不许嗲**：系统级语气（"晚上好，主人""对公司下达指令"）。

## 二、定稿元素清单（母版里都有，逐项还原）

- **光环**：三层椭圆粒子环（8200粒，紧环55%/中散31%/外雾14%），斜姿态 tiltK≈-0.10，色带沿环缓慢环游（hueDrift 0.012/s），呼吸 0.5Hz，边缘撒尘上飘，前亮后暗，中心极淡椭圆底光，一条扫描线缓扫。
- **导航**：悬浮文字，字距4px，当前项顶上16×2px琥珀刻线；「待你拍板」右肩5px呼吸红点（2.2s）。
- **标注引线**：细线+端点圆点钉在环上，中文主标+英文微注（`核心·在场 / CORE·IDLE·BREATH 0.5HZ`；`五人待命·记忆+2 / CREW STANDBY·MEM SYNCED`）。
- **问候**：渐变字（白→雾蓝→浅紫 background-clip），字重300，字距10px。
- **指令行**：无框。琥珀▸ + 文字 + 块状闪烁光标 + 底线（琥珀22px起笔→白28%→渐隐），右下 mono 提示（⌘↵ 执行 · 空格按住说话）。
- **质感层**：左右30vw斜纹肌理(45°, 白2.4%)；四角状态读数（MUNAEA▸深夜在线 / 实时时钟·LINK● / SCENE·状态 / MEM·CREW）；帧角编号01/02；底部巨型 MUNAEA 描边水印（1px 白4.5%）。
- **响应式**：<1180px 隐读数/编号；<760px 提示全屏观看。

## 三、待补两屏（同语法派生，出图后船主过目再施工）

- **开机（公司干活）**：环收紧加速→三人从环上"析出"为三个悬浮全息位（无框，引线标注 名字/岗位/一句话现状/微注元数据），REC 红点+时间码入右上读数，指令行变"插话"。
- **打板**：全场调暗，环退远；中央悬浮一组无框文字块（SCENE·标题·真实动过的文件 mono 琥珀），下方两个纯文字动作「批准 · 打板」（白，字距大）/「打回」（灰），选中时一根琥珀底线扫过；批准瞬间一帧白闪。

## 四、施工工艺路线

- v1 施工：照母版技术（canvas 2D 粒子精灵 + DOM/CSS），零新依赖，接进 React 前端（环=`<HaloCanvas/>` 组件，状态驱动：idle/听到指令/工作中/待拍板）。
- v2 升级（后续）：three.js 点精灵 + 泛光后期（发布会级质感），依赖引入需报备船主。
- 性能红线：60fps；`prefers-reduced-motion` 降级为静帧+缓呼吸。
