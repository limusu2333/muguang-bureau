# 房间/板块 插槽规范（2026-07-09 · 从会议室/执行室抠出来的模子）

> 船主的本意：**公司＝一堆能插拔的板块，缺什么就做块板插进去。** 这张规范＝"当一块板得满足啥"的模子。
> 定这一次，以后工具间/编程部/编辑部/经理办公室…每一间都照着填，插多少板都不跑偏。

## 一块板有两个接口（抓住这个，就抓住全部）
1. **插槽接口**＝这块板**怎么卡进公司**（扩展性——你的"缺什么插什么"就靠它）。
2. **契约接口**＝这块板**吃什么、吐什么**（防垃圾——两块板各自都插好，但交接的东西没说定形状，拼起来还是垃圾；79% 的翻车在这）。
> 铁律：**板与板之间交"说定形状的东西"，不交一段聊天。**

## 参照实现（都是现役、能用的板，照它抄）
| | **执行室**（能力/工具板） | **会议室**（协作场所板） |
|---|---|---|
| 干啥 | 跑命令验代码（测试/编译/只读） | 发起一场会、维持秩序、共享桌面 |
| 入口 | `run_command(命令, 工作目录)` | `开会(议题, 参会, 召集人, progress, 会话id)` |
| **吃**（输入契约） | 一条命令(str) | 议题+参会岗位+召集人 |
| **吐**（输出契约） | `ToolResponse`(输出/退出码) | `(桌面纪要, 结束原因)` |
| 插槽（怎么插进来） | `执行室工具()`→`FunctionTool(name="run_command")`→装进干活工具集 | `平台_工具集.hold_meeting` 工具→本人在干活时召集 |
| 留痕 | `执行室/记录/YYYY-MM-DD.jsonl` | `会议室记录`（开一场会/记一句） |
| 规则牌 | docstring：能力/权限/可见性/诚实边界 | docstring：只管场地规则、不藏模型替人拿主意 |

## 一块板的解剖（7 件，缺一不可）
1. **独立模块**：自己一个 `工具/<房间>.py`，`COMPANY = Path(__file__).resolve().parents[1]` 自扎根。
2. **规则牌**（模块顶 docstring）：①为什么有这间房 ②能力（交给人：怎么用、判断留给活人）③权限（焊平台：能不能做、白名单/红线写死在代码）④可见性（留痕）⑤诚实边界（这块**不**干什么、别拿它假装能力）。
3. **入口函数**：一个清清楚楚的 callable＝"调它会发生什么"。
4. **契约·吃**：入口的参数＝定死的输入形状（类型+含义写进 docstring 的 Args）。别让上一块板塞给它一段含糊的话。
5. **契约·吐**：`ToolResponse`（给 agent 用）或结构化返回（给编排用）。**这就是交给下一块板的"东西"**——固定、可预期。
6. **留痕**：`_留痕()`→`<房间>/记录/YYYY-MM-DD.jsonl`，**场所自己记自己干了啥**（圣域⑫，不靠调用方记得落盘；留痕失败不许拖垮主流程）。
7. **插槽**：`<房间>工具()`→`FunctionTool(英文name)` 装进工具集（能力板）；或作为服务函数被编排/别的工具调用（场所板）。**英文 name**（避 OpenAI 中文工具名 400）。
> 有状态的板（会议桌面/执行白名单/在岗表…）：**状态由这块板自己持有、自己守**，别人不能手工乱改（防表演/防脏写）。

## 建一块新板的清单（照抄即插）
- [ ] 新建 `工具/<房间>.py`，扎根 COMPANY。
- [ ] 写规则牌 docstring：为什么有 + 能力/权限/可见性 + 诚实边界。
- [ ] 定入口函数：**吃什么**（参数=输入契约，写清 Args）、**吐什么**（ToolResponse/结构化=输出契约）。
- [ ] 加 `_留痕()`→`<房间>/记录/*.jsonl`。
- [ ] 有状态就自己持有、自己守，别人只读。
- [ ] 导出 `<房间>工具()`→英文 name 的 FunctionTool，装进对应工具集。
- [ ] 写 `if __name__=="__main__"` 自检（不烧钱，验入口+留痕）。
- [ ] 接进去后**真跑原场景回归**：谁开口/会议/插话/干活全链不被带崩（铁律①不破坏现有功能）。

## 两条边界铁律（抄两块板的魂）
- **场所不藏模型替人拿主意**（会议室）：房间只管"场地规则+留痕+把东西摆上桌"，"该谁做、够不够、行不行"是走进来的活人判断。
- **能力交给人、权限焊平台**（执行室）：怎么用交给活人自己判断；能不能做（白名单/红线/删钱密钥）焊死在代码里。
