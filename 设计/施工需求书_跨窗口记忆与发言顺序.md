## 工单A：跨窗口记忆（抄 ChatGPT 注入格式 + Claude 工具二件套 + 全文索引起步）

### A1 近期会话摘要（ChatGPT "Recent Conversation Content" 的抄件）
新建 `工具/会话摘要.py`：
- `生成昨日摘要()`：读昨天的大厅对话档案（路径从 大厅记录.py 推），用 `升级_模型层.建Agent("文案工程师（兼职）", ...)` 蒸馏成 1~2 行：`MMDD 聊了<主题>：<要点，含具体名词/数字>`。追加到 `记忆库/会话摘要.md`，只保留最近 40 行。当天没档案/已生成过则跳过。
- 幂等与节流：状态记在 `记忆库/.巩固状态.json` 的 `"_会话摘要"` 键（日期）。
- 挂钩：`记忆巩固.巩固到期的人()` 开头先调它（同一个后台线程顺路跑，失败只写 `记忆库/抽取日志.md` 不外抛）。

### A3 检索工具（Claude conversation_search / recent_chats 的抄件）
新建 `工具/大厅检索.py`：
- SQLite 索引落 `运行状态/大厅索引.db`，FTS5（先探测 trigram tokenizer 可用性：`CREATE VIRTUAL TABLE ... USING fts5(text, tokenize='trigram')` 失败则降级为 unicode61 + LIKE 混合扫描，降级路径必须能跑）。
- 增量索引：按档案文件 mtime 记账，变了才重索引该文件。
- `搜历史(query: str, 条数: int = 5)` → 返回列表[{"时间","谁","命中","前后文"}]（命中行前后各带1-2句）。
- `翻近期(天数: int = 3)` → 返回最近N天的会话摘要行 + 每天最后3句原文。
`工具/平台_工具集.py` 注册两个工具 `搜历史`/`翻近期`（只读，出参截断防刷屏，单次返回≤1500字）。
**关键**：`活_本人.唤醒本人` 的 `只发言=True` 路径目前若不带工具，则给只发言者配一个**最小工具箱（仅这两件）**，并在其系统提示加一行："记不清过去聊过什么时，先用 搜历史/翻近期 翻档案再开口，别凭印象编。"

## 工单B：发言顺序升级（抄谋杀之谜三规则 + relaychat/multi_bot_control 机制）

### B1 顺序=分数不是座次
`常识门.过门`：普通聊天名单不再按花名册次序——每人用已算出的 `分` 排序（分数含相关度/存在感/频率，每轮自然不同），同分加随机抖动 tiebreak。直通名单保持优先级排序（点名>任务>全体>地盘）在前。

### B2 回评唤醒（AI 的话也能勾人；配 multi_bot_control 式安全阀）
`办公室._main` 顺序群聊循环里：每当有人说完一句（非沉默），对**他这句话**跑一次 `常识门._提及检测`——若点到了本轮还没说过话的同事，把该同事插进后续序列（原因："同事在喊你"）。安全阀：**每轮此类连锁追加最多 2 人**；被追加者仍走本人判断（可[沉默]）。
### B3 节奏
序列中相邻两次唤醒之间 `await asyncio.sleep(random.uniform(0.8, 2.0))`（relaychat 的连锁延迟机制，模拟真人错峰）。`random` 在此处允许（后端运行时，非工作流脚本）。
