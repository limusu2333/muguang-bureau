# 群聊语义提案 v2（2026-07-03 三路社区调研后重写；只提案未施工）

废弃 v1（掷骰子方案，船主判死：装出来的性格，长期必违和——判得对，调研证实）。

## 一、三路调研的收敛结论

三路独立去扒（中文群bot生态 / 国外框架源码 / 全网口碑面），指向同一个架构，且和我们活公司的魂同构：

> **"说不说话"的最终主权必须在每个人自己手里（带着他自己的记忆和人设让模型判断）；
> 便宜的规则只做"常识与礼貌"的门，不做导演。**

### 证据链（谁在用、多少人认）
- **MaiBot（麦麦，5.4k★，日更，B站教程32.7万播放）**——全网唯一把"何时说话"当核心问题连做两代的项目，口碑原话："像真人一样，会潜水几小时突然冒出来插一嘴，**群友很难判断这是不是真人**"。中文赛道断层第一。
- **斯坦福 Generative Agents（21.7k★，领域开山论文）**——源码证实：先过几条零成本常识过滤（在睡觉不聊/刚聊过冷却/正忙不插），然后**带人设+检索记忆让模型自己答 yes/no**。各自判断，无中央导演。
- **ChatGPT 群聊（OpenAI 2025-11）**——"何时闭嘴"口碑最佳的大规模实现：默认自主判断何时回应何时安静，实测"憋到有人真的问了才给建议"；**不说话时用 emoji 表示在场**。
- **学术共识（arXiv 2412.04937 等）**：被问者必答（adjacency pair）+ 其余人按内心冲动自荐，混合最像人、崩坏最少。
- **反面共识（全生态一致）**：AutoGen 导演点名=必有人说无人可沉默，真人感硬伤；c.ai 最响差评="一人话痨其他人消失在虚空"；**一切翻车的根源=把发言当默认、把沉默当异常**。

## 二、要搬的东西（每样都有出处，多数可直接照抄）

### A. 常识门（抄 MaiBot `reply_necessity.py`，纯规则零成本——这不是导演，是礼貌）
每条消息对**每个人**各算一个分，≥阈值才唤醒这个人：
- 强相关：被@=100（直通）｜名字被提到=80｜普通群消息=0
- **喊的是别人就不抢话**（MaiBot 连"群友在喊 DeepSeek/豆包"都识别不接茬——搬成"喊老纪时其他人不动"）
- 内容分：真问题+15 / 请求"帮我…"+20 / 征询"你觉得…"+20 / 纯"哈哈/草/6/？"−25
- **存在感惩罚：近5分钟自己每说一句−15、连续发言每句−20**——这是"防几个AI互相刷屏"的现成答案
- × 每人发言频率系数（talk_value 0~1，船主可调的滑杆）
- 任务/需求类内容 → 老钟无条件过门（他职责牌的"任务必接"，规则只是执行他已有的职责）

### B. 本人终审（抄 Generative Agents `decide_to_talk` + MaiBot Planner——主权在人）
过门的人才醒，醒来带自己的四区记忆+全部上下文，**自己选**：说 / [沉默] / 等一等再看。
- 兴趣的本源抄 MaiBot 老架构的洞察：**兴趣 = 这句话激活了我多少记忆**——和刚建成的记忆系统直接咬合：聊到老纪记忆里有的事，他自然来劲。用得越久越像他自己，真人感随时间变厚（回应船主"长期违和"之问）。
- "皮一下"不再是骰子：性格写在人设里（"老纪话少但质量的事憋不住"），冒不冒泡是他带着性格判断出来的。

### C. 节奏工程（抄 AI Town 常量 + MaiBot 血泪 issue）
- 打字机+一次一人播放：已有 ✓
- 冷场兜底=老钟：已有职责牌 ✓
- 说完泄劲：MaiBot 意愿−1.8 思想 → 已被 A 的存在感惩罚覆盖
- **主动发言（冷场救场/主动关心）本期不做**：这是全生态翻车最高发区（MaiBot #1786"唠叨王"、Shapes 半夜打电话、Butterflies 模板化尬贴），做就必须配指数退避+无人接茬即闭嘴+给记忆补"因"（AstrBot RFC #3497）。放下期，单独立项。

### D. 场所常识补丁（治老纪的误会，一句话）
规则牌加："在大厅说话＝把话直接说出来，你的发言本身就是回复，不需要写任何文件、不需要任何权限。"

## 三、和"活公司真谛"的关系（回应船主"这不是又回到规则控制吗"）
不是。A 层规则管的全是**礼貌与在场状态**（别人被点名不抢话、刚刷过屏歇一歇、"哈哈哈"不值得醒）——真人也被这些常识管着，这不是导演派活。**要不要说、说什么，永远是本人带着记忆做的判断（B层）**。对比 v1 的骰子：骰子替人决定"想说"，门只决定"这句话值不值得把人叫醒"。
