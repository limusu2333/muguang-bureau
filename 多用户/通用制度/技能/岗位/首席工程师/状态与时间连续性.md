# 岗位技能 · 状态与时间连续性
> 目的：让状态层、生活层和时间逻辑经得起停机、跨天、重启和长期运行。

## 必查场景
1. 第一次启动、空状态、损坏状态。
2. 停机后恢复：1小时、24小时、72小时、跨月。
3. 进程中断：写到一半被杀，重启后不重复、不丢失。
4. 时间回拨或系统时间异常。
5. 多次触发同一事件时是否幂等。

## 实现纪律
- 状态写入走原子写或临时文件替换。
- 记录事件来源、时间、输入摘要和结果。
- 不能只存最终值；关键转变要留流水。
- 测试必须覆盖至少一个时间跳变和一个重启恢复。

## 输出格式
`状态对象 / 时间假设 / 恢复策略 / 测试覆盖 / 剩余风险`
