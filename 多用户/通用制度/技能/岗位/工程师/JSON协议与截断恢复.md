# 岗位技能 · JSON协议与截断恢复
> 目的：让工程师处理模型 JSON 输出时区分语法错误、提示词错误和 token 截断，不浪费预算。

## 判断顺序
1. 是否完全没有 `{}`：提示词可能没约束住或模型拒答。
2. 是否有开头没结尾：优先判断 token 不够或接口截断。
3. 是否字段缺失：提示词字段设计不清或模型未加载上下文。
4. 是否 JSON 内混入 Markdown：提示词需明确“只输出对象”。

## 修复策略
- 能一次给足合理预算，就不要用小预算反复试。
- 只在空回复、明显截断或接口错误时重试。
- 语法可修复时先提取对象，不要求模型重复整段。
- 仍失败时报告原始短摘要和失败类型。

## 输出格式
`失败类型 / 证据 / 修复方式 / 是否重试 / token预算建议`
