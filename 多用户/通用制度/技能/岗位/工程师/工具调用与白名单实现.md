# 岗位技能 · 工具调用与白名单实现
> 目的：让工程师实现读文件、写文件、执行命令等工具协议时守住权限边界和可追溯性。

## 实现要求
- 每个动作先校验当前派活/历史工单白名单，再执行。
- 读文件、写文件、执行命令、请示、申请技能都要有明确日志。
- 未知动作不吞步，必须暂停并说明原因。
- 命令输出要截断保存，既能追溯又不炸上下文。

## 权限边界
- 白名单外写入：拒绝并请示。
- 删除/覆盖：默认红线，交项目经理或平台维护者。
- 外部网络、第三方脚本、密钥操作：默认请示。
- mock 模式和真模式必须有明显标识。

## 输出格式
`动作 / 校验结果 / 执行结果 / 日志位置 / 需请示项`
