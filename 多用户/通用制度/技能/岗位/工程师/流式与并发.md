# 岗位技能 · 流式与并发
> 目的：让工程师处理长等待任务时给船主进度反馈，避免界面干等或串行拖慢。

## 适用场景
- 点名、自检、并行岗位请求。
- 长模型调用、批量核验、日志尾随。
- 前端需要秒表、阶段提示或 SSE 流式输出。

## 实现纪律
- 独立岗位/独立任务优先并行，除非存在明确依赖。
- 每个并发任务单独计时，失败不拖死全局。
- 前端先显示“已发起/进行中”，再逐条追加结果。
- 后端输出必须可被中断、可超时、可记录错误。

## 禁止
- 只在全部完成后一次性返回长文本。
- 用无限重试伪装稳定。
- 并发写同一个文件却没有锁或归并策略。

## 输出格式
`并发对象 / 进度事件 / 计时字段 / 超时策略 / 失败展示`
