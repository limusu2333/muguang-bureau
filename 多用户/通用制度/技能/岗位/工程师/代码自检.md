# 岗位技能 · 代码自检
> 目的：让工程师在提交接口、通道、模型接入和工具调用代码前，先把会坏的边界查出来。

## 自检优先级
1. 密钥、账号、endpoint、真实返回字段是否泄露或误写死。
2. timeout、重试、限流、空回复、半截 JSON 是否处理。
3. mock 模式与真模式是否清楚分开。
4. 花名册登记值与服务端返回 `model` 字段是否核对。
5. 错误信息是否说人话，并带失败阶段。
6. 文档、README、班规是否与实际行为一致。

## 自检方法
- 改配置键、模型名、路径名之前，先用 `rg` 查全仓引用。
- 接口调用必须限制 token、timeout 和重试次数。
- JSON 解析失败先判断是语法问题、截断问题，还是提示词/预算问题。
- 能用一次足量预算解决的，不用小预算反复重试浪费额度。
- 写完先跑允许的本地检查；跑不了就说明原因和剩余风险。

## 输出格式
`已核对 / 发现的问题 / 已跑测试 / 未跑测试与原因 / 是否需要项目经理审批`
