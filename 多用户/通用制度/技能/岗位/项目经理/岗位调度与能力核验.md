# 岗位技能 · 岗位调度与能力核验
> 目的：让项目经理按真实能力派活，不按模型名想象员工会什么。

## 调度顺序
1. 先读 `花名册.yaml` 的 abilities、modality、routing。
2. 再看最近点名缓存的服务端 `model` 字段和自检状态。
3. 需要看图、真实 API、长上下文、代码实现、文档事实校对时，按岗位能力分配。
4. 登记能力与现场表现冲突时，先安排低成本核验，再决定是否转岗或上报。

## 岗位匹配
- 复杂拆解、审批、跨岗冲突：项目经理。
- 核心工程、状态/生活层、多文件改造、视觉实现：首席工程师。
- 模型/API、通道、流式、错误恢复、工具调用：工程师。
- 文档、公告、制度同步、事实归档：文案工程师（兼职）。
- 反证、回归、验收、独立核查：测试工程师。

## 输出格式
`任务类型 / 推荐岗位 / 能力证据 / 风险 / 是否需要核验`
