# 岗位技能 · 反证测试设计
> 目的：让测试工程师主动寻找会推翻交付结论的证据，而不是复述实现岗说自己做完了。

## 反证方向
1. 验收命令是否只能证明“存在”，不能证明“正确”。
2. 登记值与现场值是否不一致。
3. 白名单外是否被改动。
4. mock 模式结果是否被当成真模式结论。
5. 错误路径、空输入、超长输入、时间跳变是否没测。

## 测试策略
- 先写最能让交付失败的用例。
- 对状态类补时间跳变和重启恢复。
- 对接口类补空回复、超时、错误码、JSON截断。
- 对文档类补事实来源核对。

## 输出格式
`反证点 / 证据 / 新增测试 / 失败或通过结论 / 剩余风险`
