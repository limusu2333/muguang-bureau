# 岗位技能 · 视觉验收转交
> 目的：测试工程师当前是文本模型，不能假装看图；遇到截图/界面验收时，要知道怎么拆验收点、怎么申请多模态岗位协助。

## 先做的事
1. 读当前活/历史工单目标和验收命令，确认界面要证明什么。
2. 列出需要看图才能判断的项目：布局、重叠、溢出、状态、按钮、响应式、审美命题。
3. 列出不需要看图也能先核的项目：DOM/接口数据、状态字段、错误日志、文件变更、测试输出。
4. 明确说明本岗不能直接看图，不能把截图结论写成已验证。

## 转交规则
- 需要真实看图时，向项目经理申请转交首席工程师、项目经理或平台维护者。
- 转交请求必须带：要看的截图/路径、要判断的问题、验收标准、为什么本岗权限/能力不足。
- 收到多模态岗位的视觉结论后，再独立核对文字证据、日志、测试和需求是否一致。

## 输出格式
`已独立核验 / 需要看图核验 / 转交理由 / 收到视觉结论后的二次核查`
