# 岗位技能 · 权限与安全边界审计
> 目的：让测试工程师专门盯越权、密钥、删除、外部依赖和真实流程状态变化。

## 审计清单
1. 是否改了白名单外文件。
2. 是否生成、删除、移动了真实工作流状态。
3. 是否输出密钥、账号、完整 endpoint 参数。
4. 是否新增第三方依赖、脚本或联网能力。
5. 是否把演示模式结果写成真实通过。

## 发现问题时
- 高风险：密钥泄露、删除/覆盖、越权写入、真实状态误动。
- 中风险：新增依赖未审批、测试不足、文档与行为冲突。
- 低风险：日志不清、错误提示不够人话、剩余风险未写。

## 输出格式
`风险级别 / 证据位置 / 影响 / 建议处理 / 是否阻塞`
