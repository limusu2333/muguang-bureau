# 通用技能 · 工作质量门
> 目的：每件活不是“做完就算”，而是按任务类型通过对应闸门。闸门就是必须检查的关口；历史工单也按同一标准验。

## 入口判断门
项目经理派活前必须判断任务属于哪些类型：
- 代码改动：需要代码审查、测试、文档同步。
- UI/视觉：需要截图/视觉审查。
- 模型/API/外部状态：需要登记值+现场值核验。
- 项目核心：需要公司目的与项目资料对齐检查。
- 文档/公告：需要事实来源、证据等级、署名与日期。
- 技能缺口：需要 skill 申请或已有 skill 对照。

## 执行门
员工每一步都要能回答：
1. 我现在依据哪条派活/历史工单/班规/总纲？
2. 我查到的证据是什么？
3. 我有没有越过白名单、费用、密钥、删除、架构这些边界？
4. 这一步的结果能不能在大厅、会议室、请示台、待验收或历史项目室被船主追溯？

## 出场门
完成前必须满足：
- 交付物存在且在白名单内。
- 验收命令已跑，或说明为什么无法跑。
- 代码/视觉/事实/项目对齐中命中的审查项已处理。
- 完成动作带结构化复盘：做对、做错、下次。

缺一项不能完成，应请示或暂停。
